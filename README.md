# TneXa - Technology Network for AI

Building the 6 engines of agentic and multimodal AI.

TneXa is a modern AI platform focused on orchestrating autonomous agents and providing specialized infrastructure across six key domains of artificial intelligence expertise.

## 🚀 The 6 AI Engines

- **TneGa (Agents)**: Orchestrate, manage, and deploy autonomous AI agents.
- **TneKa (Knowledge)**: Connect agents to enterprise knowledge with vector search.
- **TneMa (Models)**: Route and fine-tune large language models at scale.
- **TneLa (Learning)**: Specialized machine learning and data pipelines.
- **TneRa (Resources)**: Reliable cloud infrastructure and ops for AI.
- **TneVa (Vision)**: Semantic analysis of images and videos.

## 🛠 Tech Stack

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS (Modern design system)
- **Internationalization**: [i18next](https://www.i18next.com/) (English & French supported)
- **Design Aesthetic**: featuring glassmorphism and modern animations.

## 🏁 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd TneXa
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🌐 Multi-language Support

The project supports both English and French. You can switch languages using the toggle in the header.

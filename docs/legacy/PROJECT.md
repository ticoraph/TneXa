Universal Commerce Protocol (UCP)

One of the most important emerging standards for Agentic Commerce.

Topics include:

* protocol overview
* capabilities
* checkout
* discovery
* authentication
* payments
* merchant integration
* SDKs
* implementation guides
* architecture
* examples

UCP defines a common language allowing AI agents, merchants and payment providers to interoperate without custom integrations. It is designed around discoverable capabilities and supports transports such as REST, MCP and A2A. (ucp.dev⁠￼)
